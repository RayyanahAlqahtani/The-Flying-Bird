# Flying Bird Game 🎮🐤

A classic 2D arcade game inspired by the famous Flappy Bird, built from scratch using the Unity game engine. The game utilizes custom physics, fluid movement mechanics, and dynamic obstacle spawning to provide an engaging and challenging gameplay experience.

---

## ✨ Features
* Addictive Core Gameplay: Easy-to-learn, hard-to-master single-key or tap controls to keep the bird airborne.
* Procedural Obstacles: Endless pipe generation with randomized heights to constantly challenge the player's reflexes.
* Score & High-Score System: Real-time score counter with local storage to save and track your highest personal record.
* Custom 2D Sprites: Clean, lightweight 2D animations, assets, and environmental backgrounds tailored for smooth performance.

---

## 🛠️ Built With
* Game Engine: Unity (2D Project Configuration).
* Programming Language: C# scripts handling physics updates, player input triggers, scrolling background logic, and collision detection.

---

## 🚀 How to Play & Run
1. Download: Clone or download this repository to your local system.
2. Open Project: Launch Unity Hub, click "Add project from disk", and select this root folder. *(Recommended version: Unity 2022 or newer)*.
3. Load Scene: In the project window at the bottom, navigate to Assets/Scenes and open the main game scene.
4. Play: Press the Play button at the top of the Unity Editor. Use the Spacebar or click the screen to make the bird jump and avoid the pipes!
